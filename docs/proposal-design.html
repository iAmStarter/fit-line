การทำงานของระบบ (System Flow)

การไหลของข้อมูลใน 2 event พร้อม guard: rate-limit, กันรูปซ้ำ (imageHash) และกติกา cal >= 150

green = ผ่าน / บันทึก
red = ปฏิเสธ / หยุด
dashed = external service
1 Event 1: รับรูป + guard
2 Event 2: postback ยืนยัน

Event 1 ผ่าน guard 3 ชั้น (rate-limit → กันรูปซ้ำด้วย imageHash → cal >= 150) ก่อนตอบ Confirm Card. เมื่อผู้ใช้กด "ยืนยันบันทึก" LINE จะยิง postback เป็น event ที่ 2 แยกกัน ระบบจึงอ่าน stash แล้วเขียนลง Google Sheet พร้อมเก็บ imageHash เพื่อกันส่งซ้ำในอนาคต
